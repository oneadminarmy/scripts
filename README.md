# One Admin Army: scripts

Free scripts, flows and prompts from the One Admin Army YouTube channel: AI and automation for small IT teams running Microsoft 365.

Each folder matches one video. Every demo uses Harbor Lane Group, a fictional company (`harborlane.example`).

## Before you run anything

- Read the script first. You are responsible for what runs in your tenant.
- Test in a lab or test tenant before production.
- Use `-WhatIf` first. Scripts that change a tenant start in report-only or preview mode where possible.
- Scripts are provided as is, with no warranty (see LICENSE).
